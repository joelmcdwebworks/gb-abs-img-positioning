=== GenerateBlocks Absolute Image Positioning ===
Requires at least: 6.3
Tested up to: 7.1
Stable tag: 1.3.3

Adds a focal point picker above the GenerateBlocks "Object Position" field and writes the selection to it. Also fixes issue where an absolutely positioned image disappears when selected in the block editor.

== Description ==

Adds a focal point picker above the GenerateBlocks "Object Position" field and writes the selection to it. Also fixes issue where an absolutely positioned image disappears when selected in the block editor.

Updates are delivered from GitHub releases. Each release includes a gb-abs-img-positioning.zip package.

== Changelog ==

= 1.3.3 =
* Stop absolutely positioning the block appender on containers that hold a GenerateBlocks media block.

= 1.3.2 =
* Keep the block appender in place when a container holds an absolutely positioned GenerateBlocks media block.

= 1.3.1 =
* Check GitHub releases for updates and install the published plugin package.
